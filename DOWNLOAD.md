# Download

Official Windows releases of Video Screenshot Extractor are published on GitHub Releases:

https://github.com/nanachi1212/video-screenshot-extractor/releases/latest

Each formal release may include:

- `VideoScreenshotExtractor-Setup-vX.Y.Z.exe` — Windows installer
- `VideoScreenshotExtractor-Portable-vX.Y.Z.zip` — portable package
- `SHA256SUMS.txt` — SHA-256 checksums for release artifacts

Use only files published from the official repository release page above.

## Code signing policy

See the project's [Code signing policy](CODE_SIGNING_POLICY.md).

> Free code signing provided by SignPath.io, certificate by SignPath Foundation

The project is applying for SignPath Foundation open-source code signing. Releases published before approval may remain unsigned; future official Windows releases are intended to be signed through the verified automated build pipeline after approval.
