# Privacy Policy

Video Screenshot Extractor is a local Windows desktop application maintained by **nanachi1212**.

## Data collection

The application does not include analytics, advertising, telemetry, user accounts, or a developer-operated cloud service.

**This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.**

When a user supplies a video URL and starts a task, the application and its bundled open-source tools may connect to the website or content delivery network required to retrieve that user-requested content. Those network requests are necessary to perform the action explicitly requested by the user.

The application does not intentionally upload the user's downloaded videos, screenshots, output files, passwords, cookies, tokens, or API keys to the project maintainer.

## Local data

The application may store local settings such as the most recently selected output directory. Generated videos, audio files, screenshots, ZIP archives, and temporary processing files are stored or processed on the user's own computer.

Temporary job files are deleted after processing where practical. Existing user output files are not intentionally overwritten.

## Third-party websites and services

When the user asks the application to process a URL, the destination website may receive normal network information such as the user's IP address, request headers, and other information required by that service.

Users should review the privacy policy of the service whose URL they choose to process. Common examples include:

- YouTube / Google: https://policies.google.com/privacy
- Meta services, including Facebook and Threads: https://www.facebook.com/privacy/policy/
- X / Twitter: https://x.com/en/privacy

The project also bundles or uses open-source components documented in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md). Those components run locally as part of the user-requested processing workflow.
